# Privacy notice for the EXAM/STUDIO test API

This is a sandbox demonstration API. It does not ask for or store names, email addresses, account credentials, payment details, or quiz attempts. Its Cloudflare D1 database contains only the sample plan records and one sample question used by the demo.

Requests are processed by Cloudflare Workers. Cloudflare may process standard request metadata under its own privacy terms. The Premium checkout link redirects to Polar Sandbox; checkout is outside this API and test payments are not processed.

This API is provided for testing. Do not submit personal or payment information.
